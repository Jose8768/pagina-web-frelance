# Portafolio Freelance

Sitio web estático profesional para presentar servicios, metodología Scrum y propuestas de trabajo freelance.

## Archivos

- `index.html` – estructura completa del sitio
- `styles.css` – estilos visuales y responsive
- `script.js` – comportamiento mínimo del formulario

## Cómo abrirlo

Puedes abrir `index.html` directamente en el navegador o ejecutar un servidor local:

```bash
cd freelance_portfolio
python -m http.server 8000
```

Luego entra a `http://localhost:8000`.
